| Vertical Scaling                            | Horizontal Scaling               |
| ------------------------------------------- | -------------------------------- |
| Also known as scale up                      | Also known as scale out/sharding |
| Adding more power to servers eg : CPU , RAM | Adding more servers              |

When to use what ?

| Vertical Scaling            | Horizontal Scaling          |
| --------------------------- | --------------------------- |
| Traffic is low              | For large scale application |
| Simplicity is the advantage | Huge traffic                |

Limitation of vertical scaling :
1. Impossible to add unlimited CPU and ram to a single server 
2. No Backup : if 1 server go down then whole website goes down completely 

That why Horizontal scaling is preferred for large scale application
