- if small website -> few servers then not necessary 
- if busy/popular website -> then it is essential 

1. Logging : 
	- Monitoring error logs
	- per server level
	- centralize logging eg : New Relic
2. Metrics :
    - Gain Business insight 
    - Aware of health of service
    - Host level Metric : CPU , Memory Eg : Grafana
    - Aggerated level metric : Performance of DB , Cache 
    - Key Business metric : daily active user , revenue
3. Automation :
    - When system get big and complex 
    - Automation tools 
    - Improve productivity
    - Continuous  Integration (code check in verified through automation)
    - Automating builds, test , deployment ..  eg : Jenkins Jobs
