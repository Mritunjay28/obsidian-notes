Website is made up of 2 types of content :-
1. Static content : Images, Videos , CSS ,  JS
2. Dynamic content : Changes according to user input

CDN keeps static content so that it is not loaded again and again from server .

HOW CDN Work ??
- User visit website 
- CDN server closest to user  - provides static content 
- CDN Server distance from users also determines the speed of website loading  
	 If far then slow loading and if close the fast content loading

Things to consider for using CDN :
- Cost - get rid of infrequent used content 
- expiry time - not too low , not too high 
- CDN Fallback /Backup - back up when cdn fail 
- Invalidating file : 1. API 2. API Versioning
