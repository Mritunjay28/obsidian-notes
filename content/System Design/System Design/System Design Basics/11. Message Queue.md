Nowadays Modern Architecture  is made up connection of small independent building blocks .

Now these de-coupled blocks we can easily develop , deploy, maintain .

For These independent building blocks communication occur through Message Queue .

==Message Queue provides communication and co-ordination for independent blocks .==

Message Queue :-
1. Support Asynchronous Communication
   ![[Pasted image 20260708082905.png|Pasted image 20260708082905.png]]
2. Producer can produce a message to queue even when consumer is unavailable .
3. Consumer can read message from queue even when producer is unavailable .
4. Eg: Photo customization service 
   ![[Pasted image 20260708083159.png|Pasted image 20260708083159.png]]

Also 
- Producer and consumer are independent , so can be scaled Independently 
- if queue size large then add more consumers 
- if Queue is almost empty reduce consumers
