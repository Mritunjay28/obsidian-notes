Dominance of C and C++
**Strengths of C/C++**:
- **High Execution Speed**
- **Low-Level Hardware Access**
**Major Limitation**: C and C++ lacked **portability** and were inherently **platform-dependent**.


Why C/C++ Machine Code is Platform-Dependent ?
- Operating System Differences 
- Processor Differences

How Java Solves Portability ?

**A. Java Bytecode (** **.class** **file)** : - 
- Java compiler (`javac`) transforms `.java` source code into an intermediate format called **Bytecode**, saved with a `.class` extension.
- **Bytecode is platform-independent**: The generated `.class` file remains identical regardless of the underlying hardware or OS
**B. Java Virtual Machine (JVM)**
- **JVM is platform-dependent**
**C. WORA Principle**
- **Write Once, Run Anywhere (WORA)**
