## 1. SQL DIVISION Implementation Techniques

****Given two relations(tables): R(x,y), S(y).****

- ****R and S****: tables
- ****x and y****: column of R
- ****y****: column of S

****R(x,y) div S(y)**** means gives all distinct values of x from R that are associated with all values of y in S.

```
SELECT x
FROM R
GROUP BY x
HAVING COUNT(DISTINCT y) =
(
    SELECT COUNT(*)
    FROM S
);
```

# 2. SQL MINUS Operator
The MINUS operator is used with two `SELECT` statements to return only those rows from the first query that are not present in the second. It filters out all common rows and keeps only the unique rows from the first result set.
```
SELECT NAME, AGE, GRADE
FROM Table1

EXCEPT

SELECT NAME, AGE, GRADE
FROM Table2;
```

# 3. SQL  Over 
suppose 
```
|Student|Class|Marks|
|---|---|---|
|A|X|95|
|B|X|90|
|C|X|85|
|D|Y|99|
|E|Y|96|
```

u want rankings based on marks 

```
 syntax : 
 FUNCTION() OVER (
    PARTITION BY column1,column2
    ORDER BY column3
)
FUNCTION() like what to do EG :- 
ROW_NUMBER() - Gives unique numbering.
RANK()
DENSE_RANK() - no gap 
SUM()
AVG()
COUNT()
MIN() / MAX()



SELECT *,
       ROW_NUMBER() OVER (ORDER BY marks DESC) AS rn
FROM Student;


result : 

|Student|Class|Marks|rn|
|---|---|---|---|
|D|Y|99|1|
|E|Y|96|2|
|A|X|95|3|
|B|X|90|4|
|C|X|85|5|


Class X and Class Y are mixed together. SQL is treating all students as one giant group.
```

if we want ranking inside each class
```
SELECT *,
       ROW_NUMBER() OVER (
           PARTITION BY class
           ORDER BY marks DESC
       ) AS rn
FROM Student;


result : 

|Student|Class|Marks|rn|
|---|---|---|---|
|A|X|95|1|
|B|X|90|2|
|C|X|85|3|
|D|Y|99|1|
|E|Y|96|2|
```


# 4. SQL  Top-N Queries 

```
### 2nd highest salary

SELECT DISTINCT salary
FROM Employee
ORDER BY salary DESC
LIMIT 1 OFFSET 1;

eg : 1st highest -> OFFSET 0  
2nd highest -> OFFSET 1
```
