# SQL Wildcard Characters
Wildcards are mainly used with the [LIKE](https://www.geeksforgeeks.org/sql/sql-like/) and NOT LIKE operators to perform flexible searches.

- ****% (Percent):**** Matches any number of characters.
- ****_ (Underscore):**** Matches one single character.
- ****LIKE:**** Finds values that match a pattern.
- ****NOT LIKE:**** Finds values that do not match a pattern.
-  "[ ]":  Represents a range of characters, used to match any single character within the range.
-  "[ ]" with ^ or !:**** Matches any character that is NOT in the specified range.


### 1. Using the % Wildcard
****1:**** Records Starting with a Specific Letter

```
SELECT * 
FROM Customer 
WHERE CustomerName LIKE 'A%';
```
 ****2:**** Records Ending with a Specific Letter

```
 SELECT * 
FROM Customer 
WHERE CustomerName LIKE '%l';
```
****3:**** Records Containing a Specific Letter at Any Position

```
SELECT * FROM Customer WHERE CustomerName LIKE '%A%';
```
****4:**** Fetching Records with 'ra' in Country Field and Removing Duplicates

```
SELECT DISTINCT * FROM Customer WHERE Country LIKE '%ra%';
```


### 2. Using the _ Wildcard
 ****1:**** Records with a Specific Prefix and Any Three Letters

```
 SELECT * FROM Customer WHERE CustomerName LIKE 'Dan___';
```
****2****: Records with a Specific Length

```
SELECT * FROM Customer WHERE Country LIKE '_______'; // 7 length word
```

### 3. Using the [ ] Wildcard
****1****: Matching One Character from a Set
This query fetches customers whose LastName starts with A, B, or C.

```
SELECT * FROM Customer WHERE LastName REGEXP '[A-C]';
```
 ****2:**** Matching Characters Outside a Range
 To fetch records from the Customer table with LastName not containing letters 'y', or 'z'. This query retrieves customers whose last names do not contain the letters Y or Z.

```
 SELECT * FROM Students WHERE LastName NOT LIKE '%[y-z]%';
```

### 4. Combining Both % and _ Wildcard
 Matching Specific Digits in a Phone Number

```
 SELECT * FROM Student WHERE PHONE LIKE '8__5%';
```


# SQL WITH Clause

The SQL WITH clause (Common Table Expression or CTE) defines a temporary result set that can be used within a query. It simplifies complex SQL statements, making them easier to read, manage and reuse.
![[Pasted image 20260528101912.png|Pasted image 20260528101912.png]]

- ****WITH:**** Starts the CTE definition, creating a temporary result set.
- ****QueryName:**** User-defined name to reference the CTE later.
- ****AS:**** Connects the CTE name with its subquery.
- ****( ) :**** Encloses the subquery (e.g., a SELECT statement).
- ****Subquery:**** Provides data for the CTE, improving readability and reuse.
- ****Flow:**** Syntax , WITH QueryName AS (Subquery) followed by the main query.
****Syntax:****

```
WITH cte_name (column1, column2, ...)  
AS (  
    SELECT column1, column2, ...  
    FROM table_name  
    WHERE condition  
)  
SELECT *  
FROM cte_name;



// - cte_name is the name of the Common Table Expression.
// - The query inside parentheses defines the temporary result set.
// - The main query uses this CTE as if it were a table.
```
if we do 

```

SELECT a, b  
FROM table1  
)

then it will return table 
a | b | 
as a table 

if we do 


WITH emp_cte(emp_id, emp_salary) AS (

```

```
### ****1:**** Finding Employees with Above-Average Salary
WITH AvgSalaryCTE (averageValue) AS (  
    SELECT AVG(Salary)  
    FROM Employees  
)  
SELECT   
    EmployeeID,  
    Name,   
    Salary   
FROM

### Finding Employees with the Lowest Salary
WITH MinSalaryCTE (min_salary) AS (  
    -- 1. Calculate the single lowest salary value  
    SELECT MIN(Salary)  
    FROM Employees  
)  
SELECT   
    e.EmployeeID,  
    e.Name,   
    e.Salary   
FROM   
    Employees e  
WHERE   
    e.Salary = (SELECT min_salary FROM MinSalaryCTE);
```

# SQL | OFFSET-FETCH Clause

The OFFSET Clause identifies the starting point from which rows are returned in a result set. It essentially skips the specified number of rows before returning the remaining rows. OFFSET can only be used with ORDER BY clause. It cannot be used on its own. OFFSET value must be greater than or equal to zero. It cannot be negative, else return error.

eg :
![[Pasted image 20260528103851.png|Pasted image 20260528103851.png]]

```
### Skip the Employee with the Lowest Salary

SELECT Fname, Lname  
FROM Employee  
ORDER BY Salary  
OFFSET 1 ROWS ONLY;
```
![[Pasted image 20260528103919.png|Pasted image 20260528103919.png]]


The FETCH Clause retrieves a specified number of rows from a result set. It cannot be used independently and must be paired with the OFFSET clause.

```
### Fetch Rows from 3rd to 6th Position

SELECT Fname, Lname  
FROM Employee  
ORDER BY Salary  
OFFSET 2 ROWS  
FETCH NEXT 4 ROWS ONLY;

- `OFFSET 2 ROWS` skips the first two rows.  
- `FETCH NEXT 4 ROWS ONLY` retrieves the next four rows, corresponding to positions 3 through 6.
  

### Retrieve the Bottom 2 Rows

SELECT Fname, Lname  
FROM Employee  
ORDER BY Salary  
OFFSET (SELECT COUNT(*) FROM EMPLOYEE) - 2 ROWS  
FETCH NEXT 2 ROWS;

- `(SELECT COUNT(*) FROM Employee) - 2` calculates the position to start fetching the last two rows.  
- `FETCH NEXT 2 ROWS ONLY` retrieves the bottom two rows.
```

# SQL UPDATE Statement

The SQL UPDATE statement is used to modify existing data in a table by changing the values of one or more columns.
- The WHERE clause specifies which rows should be updated.
- Without WHERE, all rows in the table are modified.

```
###  Update Single Column
UPDATE Customer
SET  Age = 25
WHERE CustomerName = 'Isabella';

###  Updating Multiple Columns
UPDATE Customer 
SET CustomerName = 'John', 
Country = 'Spain' 
WHERE CustomerID = 1;

###  Omitting WHERE Clause in UPDATE Statement
UPDATE Customer
SET CustomerName = 'Mike';


```

# SQL ALTER TABLE

The SQL ALTER TABLE statement is used to modify an existing table’s structure without deleting it. It helps update the design of a database as requirements change.
- Can add, delete or modify columns in a table.
- Can also rename a table or change data types and constraints.
- Useful for adjusting database structure without losing data.

****Syntax:****
ALTER TABLE table_name [ADD | DROP | MODIFY] column_name datatype;

```
### 1. ADD
ALTER TABLE Staff  
ADD Email VARCHAR(100);

**### 2. MODIFY**
ALTER TABLE Staff  
MODIFY COLUMN Address VARCHAR(100);

### 3. DROP
ALTER TABLE Staff  
DROP COLUMN Grade;

### 4. RENAME COLUMN
ALTER TABLE Staff  
RENAME COLUMN Name TO EmployeeName;

### 5. RENAME TO
ALTER TABLE Staff  
RENAME TO Employees;
```
